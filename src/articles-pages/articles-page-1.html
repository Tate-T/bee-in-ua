Пасічні ваги з GSM-модулем LTE

Пасічні ваги BH-01 та BH-04 призначені для автоматичного вимірювання ваги вуликів, температури та вологості. Пристрій передає отримані дані на вебсервер для подальшого перегляду та аналізу.

Загальна інформація про пристрій

Модель BH-01 призначена для вимірювання ваги одного вулика, а BH-04 дозволяє одночасно контролювати чотири вулики.

Пристрій оснащений GSM/LTE-модулем, який забезпечує передачу даних через мобільну мережу.

Основні можливості:

  • Вимірювання ваги вулика.
  • Контроль температури.
  • Вимірювання вологості.
  • Передача даних через GSM/LTE.
  • Перегляд показників через вебсервер.
  • Автоматичне надсилання SMS-звітів.

Основні елементи пристрою

Пристрій має такі основні елементи:

  1. Кнопка живлення.
  2. Порт зовнішнього живлення.
  3. Кнопка тарування.
  4. OLED-екран.
  5. Слот для SIM-карти.
  6. Кнопка ECO-режиму.
  7. Роз'єм GSM-антени.
  8. Роз'єм датчика ваги.
  9. Роз'єм датчика температури та вологості.

Інформація на OLED-екрані

На екрані пристрою відображаються основні параметри його роботи:

  • Рівень GSM/WiFi-зв'язку.
  • Рівень заряду акумулятора.
  • Поточна вага вулика.
  • Системний час.
  • Температура всередині вулика.
  • Зовнішня температура.

Підключення датчиків

Датчик ваги

Підключіть штекер датчика ваги до відповідного роз'єму пристрою. Перед підключенням пристрій має бути вимкнений.

Датчик температури та вологості

Підключіть датчик до відповідного порту та зафіксуйте з'єднання.

GSM-антена

Під'єднайте антену до відповідного роз'єму для забезпечення мобільного зв'язку.

Вибір мережі GSM або WiFi

Пристрій підтримує два способи передачі даних: через мобільну мережу GSM LTE (4G) або через WiFi.

Для роботи через GSM LTE необхідна SIM-карта з доступом до мобільного інтернету.

Увімкнення пристрою

Перед увімкненням перевірте підключення всіх датчиків, GSM-антени та рівень заряду акумулятора.

Натисніть кнопку живлення та дочекайтеся запуску пристрою.

Режими роботи пристрою

Повний режим

Використовується для налаштування пристрою, перевірки датчиків та контролю з'єднання.

ECO-режим

Енергозберігальний режим, призначений для тривалої автономної роботи пристрою.

Початкове налаштування WiFi

Для початкового налаштування підключіться до WiFi-мережі пристрою.

Після підключення відкрийте браузер та введіть адресу:

192.168.4.1

Після цього відкриється сторінка налаштувань, де можна змінити параметри підключення.

Налаштування датчиків ваги

Для налаштування датчиків перейдіть до відповідного розділу налаштувань.

Для моделі BH-04 доступні окремі налаштування чотирьох каналів вимірювання:

  • Scales1 — перший датчик.
  • Scales2 — другий датчик.
  • Scales3 — третій датчик.
  • Scales4 — четвертий датчик.

Загальні налаштування

У розділі Settings можна змінити основні параметри роботи пристрою.

  • Період сну пристрою.
  • USSD-код мобільного оператора.
  • Номери телефонів для SMS-звітів.
  • Параметри з'єднання.

Налаштування сервера даних

У розділі MQTT можна налаштувати параметри сервера, на який передаватимуться дані з пристрою.

Оновлення прошивки

Для оновлення програмного забезпечення використовується розділ Firmware.

У цьому розділі можна завантажити файл нової версії прошивки пристрою.

Планові SMS-повідомлення

Пристрій може автоматично надсилати SMS-повідомлення з інформацією про стан вулика та поточні показники вимірювання.

Живлення пристрою

Пристрій обладнаний акумулятором, який забезпечує автономну роботу. Для заряджання використовується зовнішній порт живлення.

Встановлення ваг на пасіці

Для початку роботи необхідно правильно встановити вагову платформу та підготувати пристрій до вимірювання.

  1. Зарядіть пристрій.
  2. Підключіть датчики та антену.
  3. Встановіть вагову платформу.
  4. Розмістіть вулик на платформі.
  5. Виконайте тарування.
  6. Переведіть пристрій у робочий режим.

Можливі несправності

Пристрій не вмикається

Перевірте рівень заряду акумулятора та підключення живлення.

Не надходять SMS-повідомлення

Перевірте наявність мобільного зв'язку, роботу SIM-карти та правильність налаштування номера телефону.

Неправильно відображається вага

Перевірте підключення датчика ваги та правильність його налаштування.
